# 校招求职全能助手

> 一个给**实习 / 校招应届生**用的纯前端求职小工具：简历 · 岗位匹配 · JD 分析 · 面试 · 投递 · Offer 对比 · 公司库。
> 单文件、零依赖、数据只存本地浏览器，**双击即可使用，不联网、不上传。**

本项目用 **TRAE / TraeCode** 从零生成，参加论坛「案例与作品」板块 `#TRAE求职作品秀` 话题分享。

🔗 **在线体验**：<https://3596994723-spec.github.io/Jianli/>（直接打开即用）

---

## 它能干什么

| 模块 | 解决什么 | 怎么用 |
|---|---|---|
| 📝 **简历写作** | 不会把经历写成亮点 | 粘贴项目/实习描述 → 自动提炼成 3–5 条可编辑、可补数字的 STAR 亮点，一键复制纯文本/Markdown |
| 🎯 **岗位匹配** | 不确定简历符不符合 JD | 粘贴 JD + 我的技能 → 本地关键词打分出"匹配度 + 命中/缺失项 + 落地建议" |
| 🔎 **JD 分析** | 拿到一条 JD 不知从哪下手 | 粘贴一条 JD → 拆解出职责要点、硬性/加分要求、技能关键词、薪资区间，并给投前自检清单，可一键存入公司库 |
| 💬 **面试对话** | 不会跟 HR 沟通 | 填基本信息生成 1 分钟 / 3 分钟自我介绍脚本；高频问答库可标记熟练度并显示进度；支持随机抽题练习 |
| 📭 **求职记录** | 投递太多记不住、卡住了没跟进 | 新增投递 → 状态看板 + 「N 天未推进」待跟进提醒；本地保存，支持 JSON 导入/导出 |
| ⚖️ **Offer 对比** | 拿到多个 Offer 不知道怎么比 | 录入薪资结构与通勤/加班/成长等 → 自动估算年薪与参考时薪，再按你的权重打分排序，标出最推荐 |
| 🗂️ **公司信息** | 感兴趣的公司信息记不住 | 本地公司资料库：CRUD、按名称/行业搜索筛选、薪资/面试难度/内推入口备注，JSON 导入/导出 |

## 快速开始

1. 用任意现代浏览器（Chrome / Edge）打开 `index.html`（或访问上面的在线体验地址）；
2. 顶部切换到对应模块；
3. 每个模块都带有「填入示例」按钮，可一键填入样例试跑。

## 技术说明

- **形态**：自包含单文件 HTML（内联 CSS + JS），无 npm / 构建 / 后端。
- **隐私**：简历、技能、问答进度、投递记录、Offer、公司信息全部存于浏览器 `localStorage`，可随时"导出 JSON"带走，不上传任何服务器。
- **口径**：亮点提炼、匹配度、JD 拆解、Offer 年薪/时薪均为**本地规则参考结果**，帮你思考与决策，不替代任何招聘筛选结论。Offer 年薪估算采用默认假设（年终按月数、签字费按 3 年摊销等），界面有注明。

## 关键提示词（创作 TraeCode 对话用）

> 你在论坛里引用 / 二次开发时可直接使用。

**1. 简历亮点提炼**
```
我正在准备校招简历。请把我下面这段项目经历，改写成 3 条紧凑、可量化的简历亮点，
每条都用「动词 + 成果数字」开头，避免空泛形容词，总字数控制在每条 40 字以内。
项目经历：{在这里粘贴你的描述}
```

**2. 面向某岗位的量裁**
```
我投的是「前端工程师」岗。请基于下面这段经历，重点向我这个岗位靠拢：
把与技术栈无关的表述弱化，突出组件化、性能优化、工程化与协作能力，
同时补齐我认为缺的量化数据。经历：{粘贴}
```

**3. 构建本项目的主提示词（脱敏）**
```
用单一 HTML 文件做一个纯前端"校招求职助手"，视觉用暖白底 #f7f1e4 + 深棕字 #3a3327、
卡片留白配合柔阴影，顶部七个 Tab：简历亮点提炼（STAR）、岗位匹配体检（关键词覆盖率打分）、
JD 分析（职责/要求/薪资拆解 + 投前自检）、面试问答库（自我介绍生成 + 熟练度 + 抽题）、
投递记录看板、Offer 对比（年薪/时薪 + 按权重打分）、公司信息整理（CRUD + 搜索 + 导入导出）。
要求零依赖、开箱即用、数据不出本地。
```
